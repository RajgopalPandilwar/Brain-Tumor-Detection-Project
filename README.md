## About the Project

This project uses **Convolutional Neural Networks (CNN)** to detect brain tumors from MRI scan images. It classifies images into categories such as:

- **Glioma Tumor**
- **Meningioma Tumor**
- **No Tumor**
- **Pituitary Tumor**

The deep learning model is trained on a dataset of labeled MRI images and achieves high accuracy in classifying the type of tumor present.

## Features

- Brain tumor classification from MRI images
- Uses CNN-based deep learning approach
- Classifies into 4 categories (Glioma, Meningioma, No Tumor, Pituitary)
- Trained on publicly available Brain Tumor MRI dataset

## Tech Stack

- **Deep Learning** - Convolutional Neural Networks (CNN)
- **Framework** - TensorFlow / Keras
- **Language** - Python
- **Tools** - Jupyter Notebook, OpenCV

## Dataset

The project uses a publicly available Brain Tumor MRI dataset containing labeled images across four categories.

## How to Run

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Jupyter Notebook for training and evaluation
4. Use the trained model to classify new MRI images
